# ✦ 宿曜录 (SuYaoLu) · 中式宿命CP推演 ✦

> **「三生石上早刻好名字，每一次对视都是久别重逢的暗号。」**

**《宿曜录》** 是一款融合中国传统民俗数理、古典天文学星宿排盘与宋代梅花易数的轻量级纯前端趣味推演 Web 应用。无需下载安装，支持全平台浏览器秒开，并内置原生 HTML5 Canvas 绘图引擎，一键生成带朱砂方印与引流二维码的高清古风姻缘庚帖海报。

🌐 **在线体验地址**：[https://shishili-code.github.io/suyaolu/](https://shishili-code.github.io/suyaolu/)

## ✨ 核心推演体系（三大传统算法引擎）

本应用从**先天名号、后天生辰、当下天时**三个维度构建了完整的测算闭环：

1. **名号五格五行（《康熙字典》繁体笔画数理）**
   * 内置《康熙字典》高频汉字繁体笔画字典，按传统姓名学规范统计繁体总笔画数。
   * 将数理尾数映射为金、木、水、火、土五行属性，通过 **5×5 五行生克矩阵（25种精细组合）** 推演双方的性格底色与互动张力（如「火金 · 真金烈火」、「木水 · 水木清华」等）。
2. **二十七星宿合盘（唐代《宿曜经》排盘体系）**
   * 依据中国古代二十八星宿天文学与《宿曜经》历法规则（去牛宿而用二十七宿循环），根据双方生辰排布本命星宿。
   * 通过二十七宿循环距离公式精确判定双方宿命关系：**本命之星、业胎、荣亲、安坏、危成、友衰**，并自动推演双向角色定位（如掌控方与受制方、前世业星与今生胎星）。
3. **天机鉴糖签（宋代《梅花易数》时间起卦法）**
   * 结合起卦瞬间的天时特征、名号数理与求测者输入的灵感数字进行模数起卦，映射《周易》经典卦象（如《泽山咸》、《地天泰》、《水火既济》等），生成专属签文与每日宜忌指引。

## 🎨 产品特性

* **零依赖纯静态架构**：全部算法引擎、字库与文案库均封装于单个 `index.html` 文件中，无需后端服务器，加载速度极快。
* **黑金新中式视觉交互**：暗夜星盘配色搭配太极罗盘加载动效，营造沉浸式古典占卜仪式感。
* **原生 Canvas 海报生成器**：纯前端离线渲染 2 倍高清分辨率《宿曜录》姻缘庚帖长图，自动排版灵魂判词、算法实测依据、朱砂篆印与专属扫码引流框。
* **模块化文案知识库**：判词数据抽离为结构化的 `KNOWLEDGE_BASE` 对象，支持零代码门槛随时扩充与自定义签文库。

## 🚀 本地运行与自定义修改

1. **本地预览**：直接下载本仓库的 `index.html` 文件，双击使用任意现代浏览器（Chrome / Edge / Safari）打开即可运行。
2. **自定义判词库**：打开 `index.html`，定位到 `<script>` 标签内的 `KNOWLEDGE_BASE` 常量，即可直接修改或新增五行组合判词、星宿解读及卦象宜忌。
